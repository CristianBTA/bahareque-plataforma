# Proceso de retiro de personal

Bahareque Software S.A.S. · Infraestructura
Versión 1.0 · Fernando Salazar · 20-may-2021

## Pasos

1. Talento humano le avisa al jefe del área y a TI que la persona se va.
2. TI desactiva cuando se acuerda. Normalmente lo primero es el correo; lo demás se va quitando.
3. El correo se puede dejar activo un tiempo para no perder mensajes de clientes.
4. El jefe decide si la persona se queda con el portátil y el celular (a veces se le descuenta de la liquidación o se le deja como bonificación).
5. Talento humano entrega el paz y salvo con la liquidación.
